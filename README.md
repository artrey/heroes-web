# Heroes Web — браузерный прототип в духе HoMM3 / HotA

Прототип пошаговой стратегии: генерируемая карта, два города (Castle и Rampart), пошаговый бой, ИИ-противник. Прогресс автоматически сохраняется в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/.

Production-билд: `npm run build`, превью: `npm run preview`.

## Управление

**Главное меню → Новая игра**: выберите шаблон карты, фракцию, число противников и seed карты.

**Карта приключений:**
- Клик на героя — выбрать; клик по карте — переместить выбранного героя по найденному пути.
- Жёлтые точки пути — клетки, доступные за этот ход; красные — не хватает очков движения.
- Клик по своему городу — открыть.
- `↵ Enter` — завершить ход. Стрелки — прокрутка карты.

**Город:** левая часть — постройки (1 в день; недоступные дешевле подсвечены), правая — найм юнитов из жилищ и гарнизон / обмен с героем.

**Бой:** активный стек подсвечен; цветной фон клеток — доступные за speed клетки. Клик на врага — атаковать (стрелять, если ranged и нет врага рядом). Клик на пустую клетку — переместиться. Кнопки «Ждать», «Защита», «Автобой».

## Структура

```
src/
  game/
    types.ts              типы
    store.ts              zustand store + persist + действия + AI карты
    data/                 справочники (units, buildings, heroes, templates)
    utils/                rng, pathfinding (A*), ресурсы
    map/generate.ts       процедурная генерация
    battle/engine.ts      пошаговый бой (15×11 поле, инициатива)
  ui/                     React-экраны (MainMenu / NewGame / Adventure / Town / Battle / GameOver)
```

## Что есть / чего нет

✓ генерация карты по 4 шаблонам, 7 типов ресурсов, шахты, сундуки, нейтральные монстры
✓ две фракции (Castle и Rampart) — по 7 уровней юнитов, по 7 жилищ, форт, ратуши, рынок, таверна
✓ герой + до 7 слотов армии, движение с MP, A*-pathfinding
✓ пошаговый бой с инициативой, контратакой, ranged, "Ждать"/"Защита"/"Автобой"
✓ ИИ карты: постройки, найм, движение к ресурсам/городам, нападение на героев
✓ автосохранение в localStorage, продолжение игры

✗ магия, навыки героев, артефакты (структуры есть, эффекта нет)
✗ кампании, мультиплеер, выбор героя при найме
✗ остальные 7 фракций HotA
✗ реальные спрайты (заменены эмодзи + цветные плашки)

## Тех. детали

- React 18 + TypeScript + Vite
- Zustand 4 c middleware `persist` (key `heroes-web-save`)
- Без внешних UI-библиотек, без графики/звука
- Карта рисуется на Canvas 2D, бой — тоже

Чтобы стереть сохранение: «Удалить сохранение» в главном меню (или `localStorage.removeItem('heroes-web-save')` в консоли).
