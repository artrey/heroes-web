# Добавление игровых иконок

Иконки хранятся отдельными прозрачными файлами `192×192`, поэтому их не нужно добавлять в общий атлас или настраивать координаты обрезки.

## Новое заклинание

1. Подготовьте прозрачный WebP размером `192×192`.
2. Назовите его `spell-<id>.webp`, где `<id>` точно совпадает с `id` заклинания в игровых данных.
3. Положите файл в `public/assets/icons/magic/`.

Например, для заклинания с `id: "chainLightning"` нужен файл:

```text
public/assets/icons/magic/spell-chainLightning.webp
```

## Новый артефакт

Используется та же схема, но с префиксом `artifact-`:

```text
public/assets/icons/magic/artifact-dragon_scale.webp
```

Здесь `dragon_scale` должен совпадать с `id` артефакта.

## Требования к файлу

- холст `192×192`;
- прозрачный alpha-канал;
- объект расположен по центру;
- по краям оставлено примерно 12–15% свободного места;
- без рамки, плашки и нарисованного фона;
- рекомендуемый формат — WebP с качеством 90–95 и alpha quality 100.

PNG можно преобразовать командой:

```sh
cwebp -q 92 -alpha_q 100 -m 6 -resize 192 192 input.png -o output.webp
```

Если файла нет или имя не совпало с `id`, интерфейс автоматически покажет иконку `unknown.webp`.
